# Group Policy Overview

## What Is Group Policy?

Group Policy is a Windows feature that allows administrators to centrally manage and configure user and computer settings in an Active Directory domain.

Administrators use Group Policy Objects (GPOs) to apply security settings, user restrictions, desktop configurations, and other administrative settings to domain users and computers.

## Purpose of This Lab

The purpose of this lab is to demonstrate how Group Policy Objects can be created, configured, linked, applied, and tested in an Active Directory environment.

This project builds on an existing Windows Server 2025 domain environment. The Active Directory domain, Organizational Units, domain users, security groups, password policy, and Windows 11 domain client were configured before this project began.

## Group Policy Tasks

This lab will include the following tasks:

* Review the existing Active Directory structure
* Create a new Group Policy Object
* Configure Group Policy settings
* Link the GPO to an existing Organizational Unit
* Update Group Policy on the Windows 11 client
* Verify that the policy is applied
* Troubleshoot Group Policy issues

## Why Group Policy Is Important

Group Policy allows administrators to manage multiple users and computers from a central location. Instead of manually configuring each computer, administrators can apply standardized settings through Active Directory.

Group Policy can help organizations:

* Enforce security requirements
* Standardize user and computer settings
* Restrict access to selected Windows features
* Configure desktop environments
* Manage domain users and computers efficiently
